# APP SIGNATURE V2

Générateur de signatures courriel Ramo, récupéré depuis la version publiée sur Manus.

Dépôt GitHub : <https://github.com/jverryramo/ramo-signature-v2>

## Utilisation locale

Ouvrir `index.html` dans un navigateur. L’application est autonome et ne nécessite
ni compilation, ni installation de dépendances.

## Source récupérée

- Application publiée : <https://ramo-signs-d5elbuzw.manus.space/>
- Fichier source publié : `signature-tool.html`
- Import local : 22 septembre 2026

Le code propre à Manus (éditeur, télémétrie et manifeste Manus) a été retiré lors
de l’import. Les images nécessaires aux signatures et le logo de l’interface sont
intégrés directement dans `index.html` afin que l’application reste autonome.
